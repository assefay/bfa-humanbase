# HumanBase
OCHA Burkina Faso — base de connaissances humanitaire interrogeable par IA.

Site : https://ocha-bfa.github.io/humanbase/ (accès réservé, connexion par lien e-mail).
Sécurité : voir le document « BFA HumanBase — Security measures and plan ». Aucune clé secrète
dans ce dépôt : la clé Supabase visible est la clé publique (anon) ; l'accès aux données
internes exige une session d'une adresse inscrite dans app_users.
